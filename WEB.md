# Мобильная веб-версия

Веб-версия использует тот же каталог историй и игру, что и приложение. Для работы на iOS и Android её необходимо развернуть по HTTPS: до публикации публичного адреса нет. Серверные маршруты `/api/*` требуют совместимого развёртывания и настройки базы; базовая игра и локальные сохранения работают без входа. Офлайн-загрузка всех ресурсов и синхронизация между устройствами пока не реализованы.

После публикации откройте адрес в Safari на iPhone или Chrome на Android. В Safari выберите «Поделиться» → «На экран Домой», в Chrome — меню → «Установить приложение» или «Добавить на главный экран». Названия пунктов зависят от версии системы. Проверьте запуск истории, сохранение и повторное открытие на каждом устройстве. Локальные сохранения браузера и установленного приложения могут быть изолированы; для переноса используйте экспорт и импорт в настройках игры.

Для локальной разработки: `npm ci`, `npm run dev`. Для проверки сборки: `npm run build`.
