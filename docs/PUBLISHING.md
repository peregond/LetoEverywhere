# Публикация LetoEverywhere

Источник проекта — https://github.com/peregond/LetoEverywhere. Игра публикуется **только через GitHub Pages**: workflow `.github/workflows/pages.yml` загружает каталог `public` при обновлении `main` или ручном запуске. Sites и прежний репозиторий SerbianSummer для публикации не используются.

1. Обновите сведения об `origin/main`, сохраните чужие изменения и работайте с актуальным кодом. Сохраняйте ID сцен, `STORY_VERSION` и совместимость сохранений, если задача не требует иного.
2. Для изменений игры обновите `APP_VERSION` в `public/release.js` и один раз выполните `npm run stamp`; поддерживайте русский и английский тексты.
3. Запустите `npm run lint`, `node --test tests/*.test.mjs` и `npm run build`; проверьте затронутые пути. Сообщите о непрошедших проверках и ограничениях.
4. Перед публикацией проверьте актуальность `main`, объедините проверенные изменения без принудительной перезаписи и отправьте их в GitHub. Дождитесь результата workflow GitHub Pages и проверьте опубликованную игру. Если доступ к GitHub или workflow недоступен, сообщите об этом и не называйте локальную сборку опубликованной.

GitHub Pages раздаёт статические файлы. Прогресс на Pages хранится на устройстве; серверные возможности прежнего размещения не следует считать доступными на Pages.
