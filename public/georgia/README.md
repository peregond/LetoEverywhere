# Грузинское лето

Отдельная браузерная новелла. Сцены и переходы находятся в `story.js`, отображение, мини-игра и сохранения — в `game.js`, оформление — в `style.css`. Весь текст отображается шрифтом Georgia с резервным системным serif. Фоны для горизонтального и вертикального экрана выбираются по ориентации.

Локальный запуск из корня проекта: `npm ci` и `npm run dev`, затем открыть `/georgia/`. Доступны главы 1–2 основной линии, короткий переход на свадьбу; Батуми и главы 3–5 пока закрыты. Игра сохраняется в localStorage отдельно от Белградского лета. Данные сценария можно расширять узлами `story.js`, сохраняя идентификаторы сцен для совместимости сохранений.

Иллюстрации сгенерированы для проекта. Музыка, звуковые эффекты, отдельные фоны локаций и дополнительные портреты пока не добавлены.
