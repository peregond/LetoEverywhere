# Грузинское лето

Отдельная браузерная новелла. Сцены и переходы находятся в `story.js`, отображение, мини-игра и сохранения — в `game.js`, оформление — в `style.css`. Весь текст отображается шрифтом Georgia с резервным системным serif. Широкие сюжетные фоны постепенно переводятся на общую композицию: на телефоне показывается центральная часть, на вебе — широкая сцена. Отдельные вертикальные варианты сохраняются там, где общий кадр ещё не подходит.

Локальный запуск из корня проекта: `npm ci` и `npm run dev`, затем открыть `/georgia/`. Доступны главы 1–2 основной линии, короткий переход на свадьбу; Батуми и главы 3–5 пока закрыты. Игра сохраняется в localStorage отдельно от Белградского лета. Данные сценария можно расширять узлами `story.js`, сохраняя идентификаторы сцен для совместимости сохранений.

Главный экран оформлен в стиле «Белградского лета»: единая широкая обложка `home-cover-wide.webp` с шестью персонажами, заголовок, круглое меню и основная кнопка начала или продолжения игры. Его стили находятся в `home.css`; сюжетные экраны используют `style.css`. Заголовок и кнопки остаются живым текстом поверх иллюстрации. Сохранения используют прежний ключ и формат.

Бортпроводница в сценах и на обложке носит тёмную форму S7 с асимметричной лаймовой полосой. Изображение `attendant-s7-dark.webp` создано с сохранением лица прежнего персонажа по фото женского комплекта из [официальной статьи S7](https://www.s7.ru/ru/media/blog/novaya-forma-bortprovodnikov/). Старый портрет сохранён в `attendant.png` как архив.

Иллюстрации сгенерированы для проекта. Музыка и звуковые эффекты пока не добавлены.
